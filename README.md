# PulseRoute Mobile

Build the complete production-grade native-ready mobile web application PulseRoute for Apex Move Dynamics, matching the attached screenshot designs exactly. Implement all requested workflows: driver shift start/pre-trip, manifest/map, stop details, navigation and rerouting, barcode scanner, proof of service/signature, exceptions, offline queue, metrics and clock-out. Use Lovable Cloud for persistent operational data, authentication, files, and backend logic as appropriate. Prioritize faithful dark mobile design, safe areas, touch ergonomics, fixed viewport, persistent bottom nav, and functioning demo interactions. Use the attached screen images as the source of truth.
